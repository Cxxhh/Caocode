浏览器扩展与你的隐私

更新于 2026 年 10 月 17 日

Caocode 浏览器扩展让桌面应用 Caocode 里的 agent 使用你浏览器中的标签页：打开网页、阅读、点击、输入和截图，全程在你眼前。本页说明它读取什么，以及这些数据去了哪里。

只有你共享的标签页

扩展只在黄色的「Caocode」标签页分组里工作：agent 打开的标签页，以及你自己拖进分组或用扩展工具栏按钮共享的标签页。它不读取你的其他标签页、浏览记录、书签、密码或 Cookie。它查看标签页列表，只是为了判断哪些在分组里。把标签页移出分组，或在该标签页上再点一次工具栏按钮，它就不再被共享。

被要求时读取什么

在共享的标签页里，agent 请求时才会读取：网页地址、标题和文字，可以点击或输入的元素，截图，网页在控制台输出的信息，它发出的网络请求，以及性能数据。扩展通过浏览器的调试接口读取这些，所以 Chrome 会显示一条“正在调试此标签页”的提示。

当 agent 请求“看你操作”且你同意时，它会记录你在该标签页里的点击和输入，直到你点「完成」。密码框里输入的内容永远不会被记录。

数据去了哪里

只交给同一台电脑上的 Caocode，不去任何别的地方：扩展通过浏览器的本地消息（Native Messaging）与 Caocode 通信，不经过网络。扩展和 Caocode 都不会把这些数据发给我们，我们也没有可以接收它们的服务器。

Caocode 会把 agent 要的内容交给 agent，就像你分享给它一个文件。agent 会把对话（包括这些内容）发送给你使用的 AI 模型（Claude Code 用的是 Anthropic 的模型，或你自己配置的服务商），适用该服务商的条款。

它绝不做的事

  • 没有统计、没有追踪、没有广告。扩展不会把你或你的使用情况发给任何人。
  • 不加载外部代码：它运行的一切都在扩展包里。
  • 不出售数据，也不交给任何第三方。
  • 对通过 Google API 获得的信息的使用遵守 Chrome 应用商店用户数据政策，包括其中的“有限使用”要求。

关闭它

退出 Caocode，扩展就无处可连。在 Caocode 的 设置 → 浏览器 里可以关闭 agent 使用浏览器。也可以直接从浏览器里移除扩展。

有问题？

Caocode 和这个扩展都是开源的：可以查看扩展的代码，或提一个 issue。
