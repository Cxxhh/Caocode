Caocode 每个版本的变化。

1.5.6

切换更快，差异更清楚

合入 BaoCode 1.5.0 及后续修复，保留 Caocode 的 Codex CLI、子代理和 Windows／WSL 环境功能。

  • IDE 保留最近查看的 5 个聊天页面，切回时保留状态，减少重新构建。
  • 侧面板复用 IDE 差异编辑器：窄面板内联显示，宽面板左右对照，并提供改动总览。
  • 缓存长文件宽度测量结果，减少重复扫描。
  • 远程 F12 跳转使用项目主机的路径规则。
  • 图片放大后可使用整个窗口，不再被原始显示尺寸裁切。
  • 消息中途的单词开头输入 / 也能唤起命令菜单。
  • 修复多个已编辑输入框互相抢焦点导致的卡死。

新对话继续直接选中所在环境的 CLI 默认模型；推理强度只在外层工具栏选择。

1.5.0

轻松 SSH

连远程服务器不用再先去终端里配 ssh：在 BaoCode 里填好地址就能连，密码、私钥、跳板机都在同一个表单里，第一次连接也不用到终端确认指纹。设置里新增了「SSH 服务器」，所有服务器集中在一处管理，每台还能单独选用哪个内核。

新功能

  • 添加 SSH 服务器：在远程项目的列表里点「新增 SSH 服务器…」，填主机、端口和用户名，登录方式可以选密码、私钥，或者「自动」（和终端里的 ssh 一样）。粘贴 user@host:port 会自动拆开，~/.ssh 里的密钥直接列出来选，密码保存在系统钥匙串里。保存后点一下就能连接，连接失败的页面和侧栏里也能直接编辑连接。
  • 跳板机：选一台已保存的服务器当跳板，经它连到目标主机，两台的密码各问各的。
  • 第一次连接新服务器时会自动记下它的指纹。服务器的指纹变了会明确告诉你；确认是服务器重装过的话，可以一键移除旧指纹再连接。
  • 设置 → SSH 服务器：列出在应用里添加的服务器和侧栏里用过的主机，可以编辑、连接、断开和删除；~/.ssh/config 里的主机单独列出，点一下就能打开这个文件。
  • 每台服务器单独选内核：「自动」（服务器上装了 Claude Code CLI 就用它，没装就用内置内核）、内置内核，或者 Claude Code CLI（没装会自动装上）。远程主机不再跟着本机的内核设置走。
  • Windows 10 也能用密码登录：安装包里自带新版 OpenSSH，系统自带的版本太旧或者没有时，会自动改用它。
  • 设置 → 关于：版本、官网、更新日志和问题反馈都在这里，也可以在 GitHub 上为 BaoCode 点 Star。原来的「账号」改名为「Git 账号」。
  • 浏览器扩展支持 Linux 了，Chrome、Chromium、Edge、Brave 和 Vivaldi 都能用。
  • 其他工具用「文件:行:列」的形式让 BaoCode 打开文件时（比如前端调试工具里的「在编辑器中打开」），会直接跳到对应的行和列。

改进

  • IDE 里打字更流畅：每次编辑只处理改动的那几行，输入法只拿光标附近的内容，打字时也不再重绘整个 IDE。
  • IDE 里切换对话标签更快：最近看过的几个对话会保留着，切回来立刻显示，滚动位置也还在。
  • 侧边栏查看改动时，用的是和 IDE 一样的 diff 编辑器：窄的时候删除的代码直接显示在文中，够宽就左右对照，右侧有改动总览，长文件也不卡。
  • 运行中回复下方实时显示的耗时、速度和 token，合并成一个开关（设置 → 通用）。
  • 使用 OpenCode 的网关时，同一个对话的请求能命中提示词缓存，更快也更省。
  • 模型菜单打开时，会直接滚到当前选中的模型。

修复

  • 放大查看图片时，图片不会再被裁在原来的大小里。
  • 切到别的对话再切回来，生成的图片、截图和读取的图片不会再消失。
  • 对话中途换成另一家的模型后，消息会发给新选的模型；正在用的模型被删掉后，会改用选择器里显示的模型，不再提示「未登录」。
  • 跳转到定义（F12）总会把目标居中，即使它已经在屏幕上。
  • Windows：界面放大后，标题栏右侧的按钮整块都能点；安装语言服务器不再报「不是有效的 Win32 应用程序」。
  • 文件管理器按各个系统自己的叫法显示（访达、文件资源管理器等）。

1.4.0

你好，Linux

BaoCode 现在支持 Linux 了：提供 Ubuntu 及其他基于 Debian 的发行版的安装包，x64 和 arm64 都有，也会像 Mac 和 Windows 版一样自动更新。另外，第一次设置模型不再是一条报错，而是一个引导。

新功能

  • Linux：在 baocode.dev/download 下载对应处理器的 .deb（Ubuntu 22.04 或更高版本，以及其他基于 Debian 的发行版）。打开文件夹和文件用的是系统对话框，右键菜单是系统菜单，文字、文件和图片都能粘贴。感谢 qyh1221 完成了这次移植。
  • Linux 自动更新：新版本会像其他系统一样下载并校验，输入密码后安装，BaoCode 随后重新打开。从 tarball 运行的版本会改为引导你去下载页。
  • 设置模型：还没有可用模型时（用 BaoCode 内置核心、还没添加上游），会弹出引导，说明什么是上游，点一下就能添加，直接打开它在 设置 → 模型 里的页面。模型一就绪，对话会自动开始，不用再点重试。在那之前，输入框下方模型的位置会显示「设置模型」，命令面板里也有。
  • 在手机上点 agent 给出的计划里的「开始」，就能开始执行，和桌面端的按钮一样。

改进

  • 上游的模型按名称排序：设置页、获取到的列表和模型选择器里都是。

1.3.0

好朋友Chrome

这次的主角是浏览器：agent 能用你自己的 Chrome 了，带着你的登录状态打开网页、点击、输入、调试，每一步都能在侧边栏里看到。agent 还能用上游的图片模型生成图片，对话里也能直接看图。BaoCode 有了自己的内置内核；agent 的改动可以在对话旁边逐段审阅；长对话打开更快，鼠标滚轮更跟手。另外修复了一批问题。

新功能

  • 浏览器：装上 BaoCode 扩展（Chrome 应用商店，或下载 zip 手动安装），agent 就能在你自己的 Chrome、Edge、Brave、Arc 里打开网页、阅读、点击和输入，沿用你的登录状态。它只能碰你共享给它的标签页（在浏览器工具栏点 BaoCode 按钮共享当前标签页）。侧边栏实时显示它在操作的页面，你也可以直接在里面操作。在 设置 → 浏览器 里开关和安装，macOS 和 Windows 都支持。
  • 浏览器调试：agent 可以看控制台和网络请求、打断点、单步执行，按源码映射看变量；能找到页面上的 React、Vue 组件和事件处理函数，分析性能、内存和用不到的 CSS，拦截和改写请求，模拟手机等设备。
  • 浏览器调试记录：共享的标签页里打开过的页面、发出的请求、控制台的错误和警告会一直记下来，不用专门录制。你说“刚才保存时报错了”，agent 会自己去翻。「详细记录」还会记下请求体和响应体、你的点击和输入（不含密码）。记录只存在本机，设置里能看到占用的空间、一键清理，超过 1 GB 会提醒。
  • 演示给 agent 看：agent 可以请你在浏览器里操作一遍，记下每一步，存成项目里的文件，之后在你的浏览器里照着重做。
  • 生成图片：agent 可以用上游的图片模型生成图片（Images API、OpenRouter 和 Gemini 这类对话接口、Codex 的 gpt-image-2）。在 设置 → 模型 里选默认的图片模型，或者选「每次询问」，在对话里挑；图片模型不会出现在对话的模型选择器里。
  • 对话里看图：工具返回的图片（读取的图片文件、浏览器截图、MCP 工具的图片）和消息里的本地图片会直接显示在对话里。点开看大图，用 ← → 翻看这个对话里的所有图片；右键可以在侧边栏或 IDE 里打开、复制路径、在访达中显示。图片文件也能在侧边栏里打开。
  • 内置内核：BaoCode 自己写的 Claude Code 内核，同样支持 CLAUDE.md、技能、子代理、命令、Hooks、插件和 MCP 服务器，远程主机上也能用。在 设置 → 通用 → Claude Code → 内核 里切换：本机装了 Claude Code 时默认用 CLI，否则用内置。内置内核只用 设置 → 模型 里添加的上游；用 Claude 订阅请选 CLI。
  • 在对话旁边审阅改动：侧边栏的编辑器和 IDE 一样，把 agent 待确认的改动直接显示在代码里，每一段都能单独撤销或保留。顶部的工具条可以跳到上一处、下一处，按文件或一次性全部保留、撤销。侧边栏的编辑器也能查找和替换了。
  • 实时用量：agent 工作时，状态行下面实时滚动显示已用时间、输出速度和 token 数；每轮结束后显示耗时、速度、费用和 token。重新打开会话，这些数字还在。
  • 状态行的提示语大多会说到 agent 刚做完的那一步，比如它跑的命令、看的文件。
  • 输入框里的「润色」：点上下文圆环旁边的按钮，让模型把你的话理顺，标签、图片、代码和路径都原样保留，可以撤销。不需要的话在 设置 → 通用 里关掉。
  • 侧边栏可以移到对话的左边：点侧边栏工具条上的按钮，或在命令面板、「视图」菜单里选「切换侧栏位置」。
  • 设置 → 外观 → 回复时滚动：选「锚定开头」后，你的消息滚到顶部就不再自动往下滚，方便从回复开头读起。
  • 设置 → 通用 可以关掉「建议下一条提示」，省下每轮多出来的那次请求；设置 → 外观 可以关掉侧边栏里的时间。
  • Stash 页面的「+」直接在右侧新建一条，马上就能打字。
  • 诊断：应用会记录窗口、界面和主题的事件日志，在 设置 → 更新 里上传诊断时一起带上，方便排查窗口不响应这类问题。

改进

  • 长对话从最后开始读，往上滚到顶时再加载更早的内容，打开快得多；很长的一轮也会分页加载。
  • 鼠标滚轮更平滑、更跟手：对话、文件树、列表和编辑器都换上了新的滚动，高刷新率屏幕上也一样顺。触控板保持原样。
  • 检查点只保存 agent 改过的文件，不再给整个项目做快照，以前可能占到几个 GB；旧的检查点仓库会自动删除，一个月没用的会话检查点也会清理。
  • 连续的几段思考合成一段显示。
  • agent 工作时发出的消息：排队的消息逐条处理；用「立即发送」插队的消息单独发送。
  • 使用统计：每天发送一次匿名统计，只包含随机生成的安装 ID、版本号、操作系统和处理器类型；设置里不再有「发送使用数据」的开关。

修复

  • 任务进行中换了模型或上游，下一条消息就会用新的，不再沿用原来的。
  • 远程项目里，拖进输入框的本机文件会先复制到远程主机。
  • NO_PROXY 里写的网段（比如 Tailscale 的 100.64.0.0/10）会绕过代理，也会传给 Claude Code。
  • 主窗口打开时回到上次的位置和大小，上次最大化的仍然最大化。
  • Windows：Alt+Tab 切回窗口后，第一次按键就能输入，画面也不会停住；电脑从睡眠中唤醒后不再被误判为卡死。
  • macOS：全屏时关闭窗口，不再留下一个黑屏的桌面。
  • 终端：bash 导出的函数（比如 environment modules 的 module、ml）能完整带进终端。
  • 资源管理器把符号链接显示成它指向的文件或文件夹，远程项目也是。
  • Stash：Windows 上 agent 写入的 Stash 不用重启就能看到；页面的筛选条件保持上次的选择；点卡片上的对话会打开这条 Stash。
  • 侧边栏：从别处打开的 agent（包括新建的）会被选中；显示 Stash 或自定义页面时，不会同时高亮之前的对话；放不下的内容会收起来，不再被挤出这一行。
  • 继续运行的子代理可以从输入框上方的那一行打开，并接着显示在它原来的卡片里。
  • 并排显示的多个对话，各自有自己的侧边栏工具条。
  • 还有一些小问题：输入法组合为空时 Tab 也能采用建议；显示小地图时表格的滚动条又能看到了；行内标签和文字垂直居中；编辑消息时编辑框能用上全部空间；自定义详情页的按钮靠右对齐；标题里带 % 的链接能正常打开。

1.2.0

Stash 来了

这是一次大更新。新增 Stash：在任何应用里随手记下想法、截图和链接，准备好了一键交给 agent 去做，每条的进展一眼看清；登录 GitHub 或 GitLab 后，还能把 issue 导入 Stash，并同步 issue 和 PR 的状态。手机版 Beta 也可以在官网下载了。此外，Git、Fast IDE、远程主机和模型设置都有不少增强，并修复了一大批问题。

新功能

  • Stash：随手记的收件箱。在 设置 → Stash 里设一个全局快捷键，在任何应用里按下就会弹出浮动面板记一条（默认不设，避免和其他应用冲突）。文字、截图、文件、链接、代码、表格、公式都能放进去，每条都有自己的编号，像 issue 一样。
  • 整理 Stash：可以置顶、拖动排序，按时间、项目、状态筛选，合并重复的便签；搜索时连图片里的文字也能搜到，也可以用 AI 按意思搜索。
  • 交给 agent：点「在 BaoCode 中实施」，选择在新的 git worktree 里开发，还是直接在当前分支上开发；也可以在对话里 @ 一条 Stash。对话和便签会自动关联，卡片上实时显示对话的状态。
  • AI 帮你写清楚：「润色」把选中的文字理顺，「说清楚」结合图片和附件把一句话补全成完整的需求，都可以撤销。
  • 账号（设置 → 账号）：用浏览器或令牌登录 GitHub、GitLab，也支持 GitHub Enterprise 和自建 GitLab。Stash 里链接的 issue 和 PR 会显示最新状态和检查结果；可以从项目的仓库导入 issue，并在你确认后回帖、关闭 issue，发出前会提醒内容里是否带有本机路径或密钥。令牌只保存在本机钥匙串里。
  • 手机版 Beta：Android 和 iOS 版可以在官网下载页下载，和电脑配对后，在手机上查看并操作电脑上的智能体。
  • 经 Cloudflare Tunnel 连手机：设置 → 手机 的公网地址可以写成 wss://域名，不必再为此关闭域名的「始终使用 HTTPS」。
  • 分支栏：对话上方显示当前 Git 分支，可以搜索、切换和新建分支；多文件夹的工作区会分别列出各文件夹的分支。agent 运行时不能切换，以免打乱它的工作。
  • 计划模式下，计划卡片上多了「开始执行」按钮，一键退出计划模式、按计划开始。
  • 每个对话可以单独切换模型；Codex 的 Fast 档也移到了这里，Responses 和 Codex 上游都支持 Fast。
  • 在对话中查找（⌘F / Ctrl+F），以及粘贴为纯文本（⇧⌘V / Ctrl+Shift+V）。
  • 设置 → 外观 → 界面大小：整体缩放文字、图标和间距；终端字号可以跟随界面大小，也可以单独设定。
  • 设置 → 自定义：项目和全局的规则、技能、子智能体、命令、MCP 服务器、钩子和插件，都能直接在设置里新建、编辑和删除。
  • 模型设置里可以给每个上游加自定义请求头，值里可以用会话 ID 和模型名变量。
  • Git：获取、拉取、推送；多仓库的项目可以选择仓库，子模块作为独立的仓库显示；提交图可以显示所有分支，标出每个提交所在的分支和标签，提交里的文件以目录树显示。
  • 文件：侧边栏可以搜索整个项目的文本；对话里的文件链接可以在侧边栏打开、预览，或在浏览器中打开；资源管理器可以「在终端中打开」，隐藏哪些文件和文件夹也可以在设置里配置。
  • Fast IDE：可以打开「以 Diff 显示智能体改动」，agent 每改一个文件就以 Diff 打开，随改随看；可以手动更改文件的语言模式；没有语言服务器时也能格式化 JSON 等文件。
  • 远程主机：状态栏的主机指示器有了菜单，可以经 SSH 直接打开远程主机上的文件，并列出最近打开过的远程文件。

改进

  • 侧边栏的智能体列表重做，支持多选，可以批量置顶、归档和删除；已归档的智能体在 IDE 里也能显示。
  • Fast IDE 默认在主窗口中打开，替换对话；想要每个文件夹一个独立窗口，可以在设置里改回来。
  • 打开较早的对话时会显示加载状态；很长的对话也更流畅了。
  • 输入框上方会显示正在运行的子代理和后台任务数量，点一下就能打开。
  • 远程项目里的快速打开不再等连接和排序，打开更快。

修复

  • 排队中的消息点「撤回并编辑」后会回到输入框，不再丢失；用「中断当前任务，立即发送」插队的消息也不会再丢。
  • 项目文件夹被删除或移走时，会用应用的语言给出提示。
  • 数据文件夹搬家时，模型服务商的密钥会一起带过去。
  • Claude Code 自带的模型总会列出，重启后也会保留。
  • 密钥被 Base URL 拒绝时会明确提示，而不是只显示一个空列表。
  • 窗口按钮的位置、编辑器图标、触控板滚动、列表的选择和高亮等多处细节，和 IDE 保持一致。
  • 还修了一批小问题，比如在网址里输入的文字跳位置、窄输入框里模型名被截断、同一条 Stash 连续保存时互相覆盖等。

1.1.0

Caocode 1.1.0c 是基于上游桌面 IDE 的首个 Codex 版本，支持 Windows 10/11 x64。

  • 使用本地 Codex CLI 运行代理，支持新建、恢复和归档会话、流式消息、工具调用及审批。
  • 可选择模型、推理强度和权限模式，模型目录来自 Codex CLI。

1.0.0

BaoCode 的第一个版本：Claude Code 的桌面应用，内置快速的 IDE。支持 macOS（Apple 芯片和 Intel）和 Windows。

对话

  • 执行步骤折叠成一行，当前任务和进度固定显示在输入框上方
  • 按文件查看 Claude 做的修改，逐个保留或撤销；检查点不会碰你仓库的 .git
  • 用 /goal 给 Claude 设定目标，它会一直工作到目标达成
  • 富文本输入框：粘贴图片、拖入文件，从编辑器复制的代码会变成对文件和行号的引用
  • 可以编辑已发送的消息、搜索历史对话，查看上下文和套餐用量
  • 多个智能体并排运行，可以放在标签页里，也可以各开一个窗口
  • 可以设置 Claude 写的提交和 Pull Request 里的署名

SSH 远程项目

  • 通过 SSH 打开 Linux 主机上的文件夹，体验和 VS Code 的 Remote-SSH 一样：窗口留在本机，文件、搜索、Git、终端、语言服务器和 Claude Code 都在远端运行
  • 从 ~/.ssh/config 里选主机，或者直接输入 user@host
  • 远端没有 Claude Code 时会自动安装，本机配置的模型在远端也能用
  • 断线自动重连；连不上时会说明原因，可以一键重试

Fast IDE

  • 编辑器、终端，以及带提交图和 Git 追溯（blame）的源代码管理
  • 沿用你的 VS Code 主题、快捷键和语言服务器
  • Markdown 文件以预览方式打开，可以像 Typora 一样直接在预览里编辑
  • 提交信息由 Claude Code 起草，你修改后提交

模型与扩展

  • 通过 Claude Code 使用其他模型：支持 Anthropic API、OpenAI Chat Completions 和 Responses，API 密钥保存在系统钥匙串里
  • 可以为 Claude Code 的各类工作分别选择模型，标题和提交信息也可以单独选
  • 插件、MCP 服务器、技能、子代理、规则、命令和钩子集中管理，claude.ai 上的技能也会同步过来

其他

  • 智能体需要你时，有系统通知、提示音和应用图标上的数字提醒；关掉窗口后，智能体仍在菜单栏或托盘里继续运行
  • 可以从访达或资源管理器直接用 BaoCode 打开文件夹，窗口也可以置顶
  • 支持中文和英文界面
  • 在后台自动更新，重启前会先询问
