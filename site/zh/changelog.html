更新日志

BaoCode 每个版本的变化。

1.1.0

QQ弹弹

这次更新打好了连接手机的基础：手机上的 BaoCode 可以和电脑配对，查看并操作电脑上的智能体。对话也加了一张缩略图，长对话一眼看清全貌、点一下就能跳过去；每轮回复下方还会显示复制按钮和这一轮的用量。

新功能

  • 连接手机（预览）：新增「设置 → 手机」，可以扫码配对，也可以让同一网络里的手机直接发现这台电脑。配对时两端核对安全码，之后经局域网或公网直连，内容端到端加密；电脑换了 IP 也不用重新配对。默认不开启，点「显示二维码」时才开始监听；macOS 第一次会询问是否允许 BaoCode 访问本地网络。手机 App 即将推出。
  • 对话缩略图：对话左侧显示整段对话的缩略图，你的消息、代码、表格、改动都能分辨出来。滚动时一块液态玻璃标出当前所在位置，玻璃下的内容会像 macOS 程序坞一样轻微放大；点击或拖动缩略图即可跳转。
  • 缩略图显示时代替右侧滚动条，消息列左右也会让出一些空间；窗口太窄时自动隐藏，恢复滚动条。
  • 设置 → 外观：可以关闭「对话缩略图」，关闭后和以前一样使用右侧滚动条；开启时还能调节液态玻璃的不透明度（0%～150%），以及它跟随滚动时上下拉伸的弹性（关闭、轻微、适中、Q 弹）。
  • 回合底栏：每轮回复结束后，下方有「复制回复」按钮和这一轮的耗时；使用 Claude Code 时还会淡淡地显示输出速度、用了多少 token 和花费，鼠标悬停可以看到明细。

改进

  • 子 Agent 对话顶部的返回按钮改为「← 对话」，箭头和文字合成一个按钮，悬停或用键盘选中时高亮。
  • 侧栏中运行中智能体的加载动画略微缩小，与列表文字更协调。

1.0.9

像素加载动画

一次小更新：智能体和子 Agent 换上了新的像素加载动画，样式和速度都可以自己选；Windows 和窄窗口下的设置界面也更整洁了。

新功能

  • 像素加载动画：智能体工作中、子 Agent 运行中都显示 3×3 的像素动画，默认为“堆满再清空”，颜色略带主题主色。
  • 设置 → 外观：可以分别为“智能体加载中”和“子代理运行中”选择加载样式（十多种可选，原来的圆环也在其中），并调节速度。

改进

  • 对话回合结束后，如果还有后台任务（子 Agent、后台命令）在运行，侧栏、对话列表和 IDE 中会继续显示运行中，直到任务完成。
  • 后台运行的子 Agent 与其他子 Agent 使用同样的加载动画；“转到后台”按钮换了新图标；输入框上方的后台命令不再转圈，改为显示终端图标。
  • Windows 上打开设置时，顶栏不再显示对话的控制按钮和标题，改为放置设置页列表的展开/收起按钮。
  • 窄窗口下设置页左右留白减小，给卡片留出更多空间。

1.0.8

精进不少

本次更新覆盖面很广：可以从站点一键导入上游，SSH 主机能在侧栏直接管理，资源管理器支持撤销和拖进拖出，第一次使用时会自动下载 Claude Code，还修复了一批长期存在的问题。

新功能

  • 一键导入上游：在支持的站点上点导入按钮，确认后即可添加上游及你自己的密钥（只导入名称、协议、地址和密钥）。设置 → 模型 顶部列出官方收录的站点，你用过的站点排在最前；收录列表随官网实时更新，不必等新版本。
  • 模型选择器显示各模型厂商的标识，每个上游的标题前也有图标。图标可以自己选（厂商标识、网站图标、emoji、内置图标或上传图片）；没设置时按地址识别厂商，或自动取站点的网站图标。
  • 排队消息：智能体工作时发送的消息不再混在对话里，而是停在输入框上方，依次发送。每条都可以撤回编辑、中断当前任务立即发送，或者移出队列。
  • 侧栏新增“打开项目”，并可以管理 SSH 主机：在本机和主机之间切换，添加、重命名、断开或移除主机。新对话的文件夹菜单也列出 SSH 主机和它们的项目，可以直接选择主机上的目录。
  • Windows 上的 SSH 支持密码登录（需要 OpenSSH 8.4 或更新版本）。
  • 资源管理器：新建、删除、移动文件都能撤销和重做（Cmd/Ctrl+Z）；可以从其他应用拖入文件，也可以把文件拖出窗口到其他应用（远程项目的文件会先下载）；远程项目的文件可以复制到系统剪贴板，本机文件也能粘贴上传进去；没有权限的文件夹会给出提示。
  • 支持自动保存：在文件菜单中开启“自动保存”，或设置 files.autoSave（停止编辑一段时间后、切换编辑器时或离开窗口时保存），与 VS Code 一致。
  • 技能页（原“自定义”）支持远程项目，可以直接管理远程主机上的技能、子 Agent、命令、规则和 MCP 服务器。新建时名称可以用中文。
  • MCP 服务器会逐个检测能否连接：连不上时显示原因（退出码、超时、需要登录）和输出日志，可以单独或全部重新检测。
  • 自动安装 Claude Code：本机没有 Claude Code 时，开始第一个对话就会自动下载并显示进度。默认使用本机已安装和 BaoCode 下载的版本中最新的一份；也可以在 设置 → 通用 中指定路径。
  • 设置 → 更新 新增“诊断日志”：遇到问题时可以附上备注，把错误日志上传给开发者，上传后会得到一个报告编号。只有点上传才会发送，日志中的用户目录会替换成 ~。
  • 设置页左侧的页面列表可以拖动调整宽度，也可以用 ⌘B 隐藏；窗口较窄时会变成抽屉。
  • GPT 等会给出思考摘要的模型，其思考过程以摘要的标题显示，展开后可以看到内容。
  • 变更审查中，改动过的图片显示为图片本身，不再显示为文本。
  • 提问卡片可以收起和展开。

改进

  • 每个模型会记住自己的思考强度和上下文长度。切换模型时不再先发一条测试请求。
  • 设置了子 Agent 模型后，所有子 Agent 都会使用它（定义为 inherit 的除外）。此前子 Agent 可能仍在使用主模型。
  • Windows 上的文字更清晰：字号对齐到像素，并改进了文字渲染，效果接近 Chrome。
  • 检查更新改为启动 10 秒后进行一次，之后每 5 分钟检查一次，新版本能更快送达。
  • 模型选择器：搜索框可以点击输入，列表上下边缘渐隐，悬停时更流畅，菜单配色与右键菜单一致。
  • 悬浮提示不超过窗口宽度的 90%，与窗口边缘保持距离。

修复

  • 停止任务后，还在运行中的工具、命令和子 Agent 不再一直转圈，而是显示为失败（Claude Code 和 Codex）。
  • 长对话的滚动条比例正确，拖动时不再乱跳。智能体自己发起的回合（例如后台任务完成后的报告）不再把对话跳到底部，也不再折叠你正在看的内容。
  • 其他工具运行 code --version 之类的命令时，不再弹出一个空白的 BaoCode 窗口。
  • SSH 取消登录或密码错误后，不再反复弹出密码框；启动时恢复的远程项目也不会弹出好几次。
  • 在 Windows 上打开 SSH 项目的变更文件列表时，不再出现灰色的错误框。
  • macOS 上，智能体运行的命令可以向其他应用发送 Apple 事件（例如用 osascript 控制其他应用），此前会被系统直接拒绝。

1.0.7

处处一样，处处不一样

本次更新以界面优化为主，并支持 VS Code 的主题插件。

新功能

  • 支持 VS Code 主题插件：在扩展视图中搜索 Open VSX，或拖入 .vsix 文件，即可安装其中的颜色主题和文件图标主题。扩展页面显示 README、功能、更新日志和兼容性，可以检查更新、切换预发布版本、启用或禁用。插件中的代码不会运行，只使用其中的主题。
  • 扩展视图分为“主题”和“语言服务器”两个页签，首页列出热门主题。
  • 新增文件图标主题选择（命令面板中的 Preferences: File Icon Theme），按上下键即可预览；JetBrains 风格的图标会按深浅色主题显示对应的画法。
  • 新增内置主题 Bao Dark 和 Bao Light，并设为默认的深色和浅色主题。
  • 输入框支持用 @ 引用文件：工作区里的文件和文件夹都能选，多文件夹工作区的每个文件夹都包括在内；输入 /、~/ 或盘符开头的路径时，可以补全本机（远程项目则是远程主机）上的任意文件。
  • 设置 → 外观新增“用户消息样式”：靠右显示为气泡（默认），或整宽显示、滚动时当前这轮的消息停在顶部。
  • 设置 → 外观新增“终端字号”：默认跟随界面文字大小，也可以单独设定。
  • 设置 → 模型中可以测试模型：在模型菜单中单独测试，或一次测试全部（每次三个）。测试通过 Claude Code 本身发起，与实际对话走同一条路径；结果显示耗时，失败时悬停可查看回复或错误。
  • ChatGPT（Codex）上游可以设置 Codex 版本：后端只列出该版本支持的模型，缺少新模型时填写更新的版本号，再刷新模型列表即可。
  • 侧边栏的对话菜单可以 Fork 对话，复制一份对话记录继续聊（远程项目同样支持）。
  • 能“在访达中显示”文件的地方都可以“另存为”一份副本；远程项目的文件会下载到本机。
  • 侧边栏“已归档”菜单新增“全部取消归档”和“删除全部已归档”。
  • 多文件夹工作区中，智能体在各个文件夹里的改动都会出现在变更审查中。
  • 智能体会知道编辑器里当前打开的文件、光标所在的行和选中的内容，就像 Claude Code 在 IDE 里那样。
  • 没有打开文件夹时，单独打开一个文件也能就它与智能体对话。
  • 上下文用量面板新增“提示缓存”：显示最近一次请求和主对话的缓存命中率，悬停可查看读取、写入和未缓存的数量。不报告缓存情况的第三方模型不显示这一项。
  • 文件图标主题支持 WOFF 字体（例如 Chalice），字体图标的大小与 VS Code 一致。

界面优化

  • 对话的空白页显示 BaoCode 标志。
  • 消息气泡和输入框的底色、边框统一；输入框获得焦点时显示投影，不再改变边框颜色。
  • 多个对话并排时，当前对话外围显示一圈半透明边框，与窗口边缘留有间距。
  • 对话滚动时，上下边缘内容渐隐。
  • 设置里的开关随界面字号缩放；标签页顶部的高亮线更柔和；标签栏两端不再有渐隐遮罩。
  • 侧边栏的变更页下方显示源代码管理的提交图，与变更一样可以折叠、调整高度。
  • 智能体侧边面板中的终端使用编辑器的背景色，与周围一致。
  • 侧边栏各分区之间的分隔线贯通左右两端。
  • 已是最新版本时，设置 → 更新中显示当前版本的更新说明。

修复

  • 压缩上下文后，上下文用量圆环会及时更新（Claude Code 和 Codex）。
  • SSH 远程项目中，跳转到定义能打开正确的文件（此前在 Windows 上可能缺少路径开头的 /）。
  • 项目内嵌套的 Git 仓库，其中的改动也会出现在变更审查中。
  • Windows 上用输入法输入时，输入框里已插入的标签和图片不再被替换成文字。
  • 从计划预览下方的回复开始拖选时，不再选中预览里隐藏的计划文本。
  • 请求上游时带上 Claude Code 的 User-Agent，避免 agentrouter.org 等中转返回 401 “unauthorized client detected”。
  • README 和 Markdown 预览中 shields.io 徽章的文字不再显示得过大。
  • 修复部分主题下代码区滚动时阴影发黑的问题。
  • 文件很多的项目第一次生成变更审查快照时，界面不再卡住几秒。
  • 中文 Windows 上，保存密钥、运行命令时不再因为 PowerShell 输出的不是 UTF-8 而出错。

调整

  • 移除 Monokai、Abyss、Quiet Light、Dark (Visual Studio)、Dark 2026、Light 2026 六个主题。正在使用它们的用户会自动切换到 Bao Dark 或 Bao Light。

1.0.6

新功能

  • 新增 ChatGPT（Codex）上游：在设置 → 模型中添加，用 ChatGPT 账号登录后，按订阅套餐的额度使用 Codex 模型，无需 API Key。
  • 一个 ChatGPT 上游可以添加多个账号，支持三种负载模式：轮询、用完再换、剩余优先。某个账号额度用尽时，请求会自动换到下一个账号。
  • 设置中可查看每个账号的套餐、已用额度和重置时间。
  • MCP 服务器请求填写信息时会弹出卡片：表单逐项填写，需要打开的链接（如授权页）确认后在浏览器中打开。

改进

  • 完全访问模式下，代理提出的问题和待审批的计划仍会弹出等你决定，其他权限请求照常自动放行。
  • 登录 ChatGPT 所需的 1455 端口被其他程序占用时，照常在浏览器中登录，再把登录后的地址粘贴回设置即可完成。

1.0.5

新功能

  • 新增网络设置：使用系统代理、手动指定代理或直接连接。可同时测试多个网站的连接，查看响应时间和连接失败的原因。
  • 新增两种内置通知音效：man-oh-yeah 和 Gulp Gulp Gulp Gulp。

改进

  • 界面文字缩放与代码字号分开控制：编辑器和侧边面板的代码视图遵循代码字号，对话文字与界面标签遵循界面缩放；字体设置修改后立即生效。
  • macOS 和 Windows 的通知音效及试听支持重叠播放，不再打断上一段声音。
  • 菜单与窗口四周保持 8px 安全边距，过长的列表在菜单内部滚动。

修复

  • 改善编辑器和侧边面板中长 diff 的滚动流畅度，修改行很多时也不再卡顿。
  • 修复对话内容组件变化时，文字选择被干扰的问题。
  • 修复拖动经过对话宽度设置时，意外改变设置值的问题。

1.0.4

改进

  • 源代码管理和侧边面板的“变更”页不再因为改动太多而卡死（比如把整个用户主目录建成了 Git 仓库）：最多显示前 10,000 项并给出提示，这时文件变化不再自动刷新，需要时手动刷新；滚动和拖动滚动条也保持流畅（#6）
  • 查看大文件或整体改过的文件的 diff 时不再卡住：diff 编辑器、侧边面板的 diff 预览和行内 blame 都改在后台计算
  • SSH 远程项目同样受这个上限保护，改动很多时不再通过 SSH 传回全部 Git 状态
  • 语言服务器的文件监听跳过 Git 对象和 node_modules 里的包文件，文件大量变化时分批处理，不再拖慢窗口

新功能

  • 侧边面板的“变更”页能识别子文件夹里的 Git 仓库，和源代码管理一致；有多个仓库时可以切换

修复

  • 智能体的目标（/goal）状态不准：放弃或出错结束的目标被当成已完成，恢复会话后也会判断错；没有任务在推进时，目标的计时仍在走
  • 对话里拖动选择文字，有时一直选不中，直到重启应用
  • 有排队消息发出或状态更新时，对话里的文字选择会出错
  • 使用 DeepSeek、智谱、阿里云等提供的 Anthropic 兼容接口时，模型列表现在能正常列出

1.0.3

Windows 上 1.0.2 打不开？

  • 如果 1.0.2 一启动就自己退出、没有窗口，应用内的自动更新也就没法用，请从 https://baocode.dev/download 下载 1.0.3 直接安装，会覆盖原来的版本，设置和对话记录都会保留。

修复

  • Windows：部分电脑上 1.0.2 启动后立即退出、不显示窗口（系统里的 Visual C++ 运行库版本较旧时会这样）。现在应用自带所需的运行库，不再依赖系统里装的版本
  • Windows：用 Volta 安装的 Claude Code 无法启动、提示命令无法识别的问题已修复

1.0.2

自动更新没装上？

  • 如果点了“立即重启更新”后应用关闭，再打开还是旧版本（1.0.0 和最早发布的 1.0.1 可能会这样），请从 https://baocode.dev/download 下载 1.0.2 直接安装，会覆盖原来的版本，设置和对话记录都会保留。

新功能

  • 设置 → 外观：可以设置代码字体、字号、连字和界面文字大小，边调边预览；终端也使用这里的字体和字号
  • 在输入框里粘贴很长的文本时，会收成一个标签（如“粘贴的文本 #1 +120 行”），不会再让窗口卡住；鼠标悬停可以预览，发送时完整内容随消息一起发出

1.0.1 的新功能

  • 对话旁边的侧边面板：浏览项目文件，查看、暂存和提交 Git 改动（提交信息可以让 Claude 起草），打开终端和智能体在后台运行的命令
  • 在侧边面板里查看 Claude 改过的文件，可以直接编辑、保存
  • 工作区：把几个文件夹放在一起，智能体同时在这些文件夹里工作；文件夹里嵌套的 Git 仓库也能识别
  • 在输入框里用 @ 引用别的对话；侧边栏里智能体的菜单可以复制会话 ID
  • SSH 远程项目支持 macOS 主机
  • 对话和 Markdown 文件里的 Mermaid 图表直接画成图，不用联网，可以放大查看
  • 显示智能体的计划卡片；对话栏的宽度可以在设置里调整
  • 资源管理器里可以复制、剪切、粘贴文件
  • 侧边面板里，后台命令的输出用真正的终端显示：终端的字体、颜色、选择、查找和链接

1.0.1 的改进

1.0.0

BaoCode 的第一个版本：Claude Code 的桌面应用，内置快速的 IDE。支持 macOS（Apple 芯片和 Intel）和 Windows。

对话

  • 执行步骤折叠成一行，当前任务和进度固定显示在输入框上方
  • 按文件查看 Claude 做的修改，逐个保留或撤销；检查点不会碰你仓库的 .git
  • 用 /goal 给 Claude 设定目标，它会一直工作到目标达成
  • 富文本输入框：粘贴图片、拖入文件，从编辑器复制的代码会变成对文件和行号的引用
  • 可以编辑已发送的消息、搜索历史对话，查看上下文和套餐用量
  • 多个智能体并排运行，可以放在标签页里，也可以各开一个窗口
  • 可以设置 Claude 写的提交和 Pull Request 里的署名

SSH 远程项目

  • 通过 SSH 打开 Linux 主机上的文件夹，体验和 VS Code 的 Remote-SSH 一样：窗口留在本机，文件、搜索、Git、终端、语言服务器和 Claude Code 都在远端运行
  • 从 ~/.ssh/config 里选主机，或者直接输入 user@host
  • 远端没有 Claude Code 时会自动安装，本机配置的模型在远端也能用
  • 断线自动重连；连不上时会说明原因，可以一键重试

Fast IDE

  • 编辑器、终端，以及带提交图和 Git 追溯（blame）的源代码管理
  • 沿用你的 VS Code 主题、快捷键和语言服务器
  • Markdown 文件以预览方式打开，可以像 Typora 一样直接在预览里编辑
  • 提交信息由 Claude Code 起草，你修改后提交

模型与扩展

  • 通过 Claude Code 使用其他模型：支持 Anthropic API、OpenAI Chat Completions 和 Responses，API 密钥保存在系统钥匙串里
  • 可以为 Claude Code 的各类工作分别选择模型，标题和提交信息也可以单独选
  • 插件、MCP 服务器、技能、子代理、规则、命令和钩子集中管理，claude.ai 上的技能也会同步过来

其他

  • 智能体需要你时，有系统通知、提示音和应用图标上的数字提醒；关掉窗口后，智能体仍在菜单栏或托盘里继续运行
  • 可以从访达或资源管理器直接用 BaoCode 打开文件夹，窗口也可以置顶
  • 支持中文和英文界面
  • 在后台自动更新，重启前会先询问
