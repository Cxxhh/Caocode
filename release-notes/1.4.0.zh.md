你好，Linux

BaoCode 现在支持 Linux 了：提供 Ubuntu 及其他基于 Debian 的发行版的安装包，x64 和 arm64 都有，也会像 Mac 和 Windows 版一样自动更新。另外，第一次设置模型不再是一条报错，而是一个引导。

新功能
- Linux：在 baocode.dev/download 下载对应处理器的 .deb（Ubuntu 22.04 或更高版本，以及其他基于 Debian 的发行版）。打开文件夹和文件用的是系统对话框，右键菜单是系统菜单，文字、文件和图片都能粘贴。感谢 qyh1221 完成了这次移植。
- Linux 自动更新：新版本会像其他系统一样下载并校验，输入密码后安装，BaoCode 随后重新打开。从 tarball 运行的版本会改为引导你去下载页。
- 设置模型：还没有可用模型时（用 BaoCode 内置核心、还没添加上游），会弹出引导，说明什么是上游，点一下就能添加，直接打开它在 设置 → 模型 里的页面。模型一就绪，对话会自动开始，不用再点重试。在那之前，输入框下方模型的位置会显示「设置模型」，命令面板里也有。
- 在手机上点 agent 给出的计划里的「开始」，就能开始执行，和桌面端的按钮一样。

改进
- 上游的模型按名称排序：设置页、获取到的列表和模型选择器里都是。
