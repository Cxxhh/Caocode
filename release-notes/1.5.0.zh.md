轻松 SSH

连远程服务器不用再先去终端里配 ssh：在 BaoCode 里填好地址就能连，密码、私钥、跳板机都在同一个表单里，第一次连接也不用到终端确认指纹。设置里新增了「SSH 服务器」，所有服务器集中在一处管理，每台还能单独选用哪个内核。

新功能
- 添加 SSH 服务器：在远程项目的列表里点「新增 SSH 服务器…」，填主机、端口和用户名，登录方式可以选密码、私钥，或者「自动」（和终端里的 ssh 一样）。粘贴 user@host:port 会自动拆开，~/.ssh 里的密钥直接列出来选，密码保存在系统钥匙串里。保存后点一下就能连接，连接失败的页面和侧栏里也能直接编辑连接。
- 跳板机：选一台已保存的服务器当跳板，经它连到目标主机，两台的密码各问各的。
- 第一次连接新服务器时会自动记下它的指纹。服务器的指纹变了会明确告诉你；确认是服务器重装过的话，可以一键移除旧指纹再连接。
- 设置 → SSH 服务器：列出在应用里添加的服务器和侧栏里用过的主机，可以编辑、连接、断开和删除；~/.ssh/config 里的主机单独列出，点一下就能打开这个文件。
- 每台服务器单独选内核：「自动」（服务器上装了 Claude Code CLI 就用它，没装就用内置内核）、内置内核，或者 Claude Code CLI（没装会自动装上）。远程主机不再跟着本机的内核设置走。
- Windows 10 也能用密码登录：安装包里自带新版 OpenSSH，系统自带的版本太旧或者没有时，会自动改用它。
- 设置 → 关于：版本、官网、更新日志和问题反馈都在这里，也可以在 GitHub 上为 BaoCode 点 Star。原来的「账号」改名为「Git 账号」。
- 浏览器扩展支持 Linux 了，Chrome、Chromium、Edge、Brave 和 Vivaldi 都能用。
- 其他工具用「文件:行:列」的形式让 BaoCode 打开文件时（比如前端调试工具里的「在编辑器中打开」），会直接跳到对应的行和列。

改进
- IDE 里打字更流畅：每次编辑只处理改动的那几行，输入法只拿光标附近的内容，打字时也不再重绘整个 IDE。
- IDE 里切换对话标签更快：最近看过的几个对话会保留着，切回来立刻显示，滚动位置也还在。
- 侧边栏查看改动时，用的是和 IDE 一样的 diff 编辑器：窄的时候删除的代码直接显示在文中，够宽就左右对照，右侧有改动总览，长文件也不卡。
- 运行中回复下方实时显示的耗时、速度和 token，合并成一个开关（设置 → 通用）。
- 使用 OpenCode 的网关时，同一个对话的请求能命中提示词缓存，更快也更省。
- 模型菜单打开时，会直接滚到当前选中的模型。

修复
- 放大查看图片时，图片不会再被裁在原来的大小里。
- 切到别的对话再切回来，生成的图片、截图和读取的图片不会再消失。
- 对话中途换成另一家的模型后，消息会发给新选的模型；正在用的模型被删掉后，会改用选择器里显示的模型，不再提示「未登录」。
- 跳转到定义（F12）总会把目标居中，即使它已经在屏幕上。
- Windows：界面放大后，标题栏右侧的按钮整块都能点；安装语言服务器不再报「不是有效的 Win32 应用程序」。
- 文件管理器按各个系统自己的叫法显示（访达、文件资源管理器等）。
