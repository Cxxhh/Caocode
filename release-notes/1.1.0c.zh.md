Caocode 1.1.0c 是基于上游桌面 IDE 的首个 Codex 版本，支持 Windows 10/11 x64。

- 使用本地 Codex CLI 运行代理，支持新建、恢复和归档会话、流式消息、工具调用及审批。
- 可选择模型、推理强度和权限模式，模型目录来自 Codex CLI。
- 输入栏新增 Fast 闪电开关，支持 /fast on、/fast off 和状态查询；关闭后保留图标，长模型名称和窄窗口下仍可操作。
- 新增 Codex 供应商管理，可导入 CC Switch（CCS）供应商，或只读连接其数据库并刷新。
- 应用名称、关于页面、快捷方式和安装包统一为 Caocode，使用独立数据目录。
- 设置中的更新改为 Cxxhh/Caocode 的 GitHub Releases，安装包更新经过大小、SHA-256 和 Ed25519 签名校验。
- 提供 Windows x64 安装包，默认按当前用户安装。

需要先安装并配置 Codex CLI。当前发布验证覆盖 Windows；SSH 远程 Codex、目标与子代理等功能仍在迁移。
