Faster switching, clearer diffs

Includes BaoCode 1.5.0 and subsequent fixes, with Caocode's Codex CLI, subagent navigation and Windows/WSL environment support.

- Keep the five most recently viewed IDE chat pages, preserving their state when switching back.
- Use the IDE diff editor in the side panel: inline at narrow widths, side by side when wide, with a change overview.
- Cache long-file width measurements to avoid repeated scans.
- Resolve remote F12 targets using the project host's path rules.
- Let zoomed images fill the preview window without clipping to their initial size.
- Open the command menu with `/` at the start of any word in a message.
- Fix freezes caused by edited input fields repeatedly stealing focus from each other.

New conversations still select the current environment's configured CLI model directly. Reasoning effort remains in the outer toolbar.
