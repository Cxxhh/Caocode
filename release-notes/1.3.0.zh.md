好朋友Chrome

这次的主角是浏览器：agent 能用你自己的 Chrome 了，带着你的登录状态打开网页、点击、输入、调试，每一步都能在侧边栏里看到。agent 还能用上游的图片模型生成图片，对话里也能直接看图。BaoCode 有了自己的内置内核；agent 的改动可以在对话旁边逐段审阅；长对话打开更快，鼠标滚轮更跟手。另外修复了一批问题。

新功能
- 浏览器：装上 BaoCode 扩展（Chrome 应用商店，或下载 zip 手动安装），agent 就能在你自己的 Chrome、Edge、Brave、Arc 里打开网页、阅读、点击和输入，沿用你的登录状态。它只能碰你共享给它的标签页（在浏览器工具栏点 BaoCode 按钮共享当前标签页）。侧边栏实时显示它在操作的页面，你也可以直接在里面操作。在 设置 → 浏览器 里开关和安装，macOS 和 Windows 都支持。
- 浏览器调试：agent 可以看控制台和网络请求、打断点、单步执行，按源码映射看变量；能找到页面上的 React、Vue 组件和事件处理函数，分析性能、内存和用不到的 CSS，拦截和改写请求，模拟手机等设备。
- 浏览器调试记录：共享的标签页里打开过的页面、发出的请求、控制台的错误和警告会一直记下来，不用专门录制。你说“刚才保存时报错了”，agent 会自己去翻。「详细记录」还会记下请求体和响应体、你的点击和输入（不含密码）。记录只存在本机，设置里能看到占用的空间、一键清理，超过 1 GB 会提醒。
- 演示给 agent 看：agent 可以请你在浏览器里操作一遍，记下每一步，存成项目里的文件，之后在你的浏览器里照着重做。
- 生成图片：agent 可以用上游的图片模型生成图片（Images API、OpenRouter 和 Gemini 这类对话接口、Codex 的 gpt-image-2）。在 设置 → 模型 里选默认的图片模型，或者选「每次询问」，在对话里挑；图片模型不会出现在对话的模型选择器里。
- 对话里看图：工具返回的图片（读取的图片文件、浏览器截图、MCP 工具的图片）和消息里的本地图片会直接显示在对话里。点开看大图，用 ← → 翻看这个对话里的所有图片；右键可以在侧边栏或 IDE 里打开、复制路径、在访达中显示。图片文件也能在侧边栏里打开。
- 内置内核：BaoCode 自己写的 Claude Code 内核，同样支持 CLAUDE.md、技能、子代理、命令、Hooks、插件和 MCP 服务器，远程主机上也能用。在 设置 → 通用 → Claude Code → 内核 里切换：本机装了 Claude Code 时默认用 CLI，否则用内置。内置内核只用 设置 → 模型 里添加的上游；用 Claude 订阅请选 CLI。
- 在对话旁边审阅改动：侧边栏的编辑器和 IDE 一样，把 agent 待确认的改动直接显示在代码里，每一段都能单独撤销或保留。顶部的工具条可以跳到上一处、下一处，按文件或一次性全部保留、撤销。侧边栏的编辑器也能查找和替换了。
- 实时用量：agent 工作时，状态行下面实时滚动显示已用时间、输出速度和 token 数；每轮结束后显示耗时、速度、费用和 token。重新打开会话，这些数字还在。
- 状态行的提示语大多会说到 agent 刚做完的那一步，比如它跑的命令、看的文件。
- 输入框里的「润色」：点上下文圆环旁边的按钮，让模型把你的话理顺，标签、图片、代码和路径都原样保留，可以撤销。不需要的话在 设置 → 通用 里关掉。
- 侧边栏可以移到对话的左边：点侧边栏工具条上的按钮，或在命令面板、「视图」菜单里选「切换侧栏位置」。
- 设置 → 外观 → 回复时滚动：选「锚定开头」后，你的消息滚到顶部就不再自动往下滚，方便从回复开头读起。
- 设置 → 通用 可以关掉「建议下一条提示」，省下每轮多出来的那次请求；设置 → 外观 可以关掉侧边栏里的时间。
- Stash 页面的「+」直接在右侧新建一条，马上就能打字。
- 诊断：应用会记录窗口、界面和主题的事件日志，在 设置 → 更新 里上传诊断时一起带上，方便排查窗口不响应这类问题。

改进
- 长对话从最后开始读，往上滚到顶时再加载更早的内容，打开快得多；很长的一轮也会分页加载。
- 鼠标滚轮更平滑、更跟手：对话、文件树、列表和编辑器都换上了新的滚动，高刷新率屏幕上也一样顺。触控板保持原样。
- 检查点只保存 agent 改过的文件，不再给整个项目做快照，以前可能占到几个 GB；旧的检查点仓库会自动删除，一个月没用的会话检查点也会清理。
- 连续的几段思考合成一段显示。
- agent 工作时发出的消息：排队的消息逐条处理；用「立即发送」插队的消息单独发送。
- 使用统计：每天发送一次匿名统计，只包含随机生成的安装 ID、版本号、操作系统和处理器类型；设置里不再有「发送使用数据」的开关。

修复
- 任务进行中换了模型或上游，下一条消息就会用新的，不再沿用原来的。
- 远程项目里，拖进输入框的本机文件会先复制到远程主机。
- NO_PROXY 里写的网段（比如 Tailscale 的 100.64.0.0/10）会绕过代理，也会传给 Claude Code。
- 主窗口打开时回到上次的位置和大小，上次最大化的仍然最大化。
- Windows：Alt+Tab 切回窗口后，第一次按键就能输入，画面也不会停住；电脑从睡眠中唤醒后不再被误判为卡死。
- macOS：全屏时关闭窗口，不再留下一个黑屏的桌面。
- 终端：bash 导出的函数（比如 environment modules 的 module、ml）能完整带进终端。
- 资源管理器把符号链接显示成它指向的文件或文件夹，远程项目也是。
- Stash：Windows 上 agent 写入的 Stash 不用重启就能看到；页面的筛选条件保持上次的选择；点卡片上的对话会打开这条 Stash。
- 侧边栏：从别处打开的 agent（包括新建的）会被选中；显示 Stash 或自定义页面时，不会同时高亮之前的对话；放不下的内容会收起来，不再被挤出这一行。
- 继续运行的子代理可以从输入框上方的那一行打开，并接着显示在它原来的卡片里。
- 并排显示的多个对话，各自有自己的侧边栏工具条。
- 还有一些小问题：输入法组合为空时 Tab 也能采用建议；显示小地图时表格的滚动条又能看到了；行内标签和文字垂直居中；编辑消息时编辑框能用上全部空间；自定义详情页的按钮靠右对齐；标题里带 % 的链接能正常打开。
