Stash 来了

这是一次大更新。新增 Stash：在任何应用里随手记下想法、截图和链接，准备好了一键交给 agent 去做，每条的进展一眼看清；登录 GitHub 或 GitLab 后，还能把 issue 导入 Stash，并同步 issue 和 PR 的状态。手机版 Beta 也可以在官网下载了。此外，Git、Fast IDE、远程主机和模型设置都有不少增强，并修复了一大批问题。

新功能
- Stash：随手记的收件箱。在 设置 → Stash 里设一个全局快捷键，在任何应用里按下就会弹出浮动面板记一条（默认不设，避免和其他应用冲突）。文字、截图、文件、链接、代码、表格、公式都能放进去，每条都有自己的编号，像 issue 一样。
- 整理 Stash：可以置顶、拖动排序，按时间、项目、状态筛选，合并重复的便签；搜索时连图片里的文字也能搜到，也可以用 AI 按意思搜索。
- 交给 agent：点「在 BaoCode 中实施」，选择在新的 git worktree 里开发，还是直接在当前分支上开发；也可以在对话里 @ 一条 Stash。对话和便签会自动关联，卡片上实时显示对话的状态。
- AI 帮你写清楚：「润色」把选中的文字理顺，「说清楚」结合图片和附件把一句话补全成完整的需求，都可以撤销。
- 账号（设置 → 账号）：用浏览器或令牌登录 GitHub、GitLab，也支持 GitHub Enterprise 和自建 GitLab。Stash 里链接的 issue 和 PR 会显示最新状态和检查结果；可以从项目的仓库导入 issue，并在你确认后回帖、关闭 issue，发出前会提醒内容里是否带有本机路径或密钥。令牌只保存在本机钥匙串里。
- 手机版 Beta：Android 和 iOS 版可以在官网下载页下载，和电脑配对后，在手机上查看并操作电脑上的智能体。
- 经 Cloudflare Tunnel 连手机：设置 → 手机 的公网地址可以写成 wss://域名，不必再为此关闭域名的「始终使用 HTTPS」。
- 分支栏：对话上方显示当前 Git 分支，可以搜索、切换和新建分支；多文件夹的工作区会分别列出各文件夹的分支。agent 运行时不能切换，以免打乱它的工作。
- 计划模式下，计划卡片上多了「开始执行」按钮，一键退出计划模式、按计划开始。
- 每个对话可以单独切换模型；Codex 的 Fast 档也移到了这里，Responses 和 Codex 上游都支持 Fast。
- 在对话中查找（⌘F / Ctrl+F），以及粘贴为纯文本（⇧⌘V / Ctrl+Shift+V）。
- 设置 → 外观 → 界面大小：整体缩放文字、图标和间距；终端字号可以跟随界面大小，也可以单独设定。
- 设置 → 自定义：项目和全局的规则、技能、子智能体、命令、MCP 服务器、钩子和插件，都能直接在设置里新建、编辑和删除。
- 模型设置里可以给每个上游加自定义请求头，值里可以用会话 ID 和模型名变量。
- Git：获取、拉取、推送；多仓库的项目可以选择仓库，子模块作为独立的仓库显示；提交图可以显示所有分支，标出每个提交所在的分支和标签，提交里的文件以目录树显示。
- 文件：侧边栏可以搜索整个项目的文本；对话里的文件链接可以在侧边栏打开、预览，或在浏览器中打开；资源管理器可以「在终端中打开」，隐藏哪些文件和文件夹也可以在设置里配置。
- Fast IDE：可以打开「以 Diff 显示智能体改动」，agent 每改一个文件就以 Diff 打开，随改随看；可以手动更改文件的语言模式；没有语言服务器时也能格式化 JSON 等文件。
- 远程主机：状态栏的主机指示器有了菜单，可以经 SSH 直接打开远程主机上的文件，并列出最近打开过的远程文件。

改进
- 侧边栏的智能体列表重做，支持多选，可以批量置顶、归档和删除；已归档的智能体在 IDE 里也能显示。
- Fast IDE 默认在主窗口中打开，替换对话；想要每个文件夹一个独立窗口，可以在设置里改回来。
- 打开较早的对话时会显示加载状态；很长的对话也更流畅了。
- 输入框上方会显示正在运行的子代理和后台任务数量，点一下就能打开。
- 远程项目里的快速打开不再等连接和排序，打开更快。

修复
- 排队中的消息点「撤回并编辑」后会回到输入框，不再丢失；用「中断当前任务，立即发送」插队的消息也不会再丢。
- 项目文件夹被删除或移走时，会用应用的语言给出提示。
- 数据文件夹搬家时，模型服务商的密钥会一起带过去。
- Claude Code 自带的模型总会列出，重启后也会保留。
- 密钥被 Base URL 拒绝时会明确提示，而不是只显示一个空列表。
- 窗口按钮的位置、编辑器图标、触控板滚动、列表的选择和高亮等多处细节，和 IDE 保持一致。
- 还修了一批小问题，比如在网址里输入的文字跳位置、窄输入框里模型名被截断、同一条 Stash 连续保存时互相覆盖等。
