Good Friends with Chrome

This release is about the browser: agents can use your own Chrome now, opening pages, clicking, typing and debugging with your sign-ins, every step of it in view in the side panel. Agents can also make pictures with your upstreams' image models, and pictures show right in the chat. BaoCode has a core of its own; an agent's changes can be reviewed part by part beside the chat; long conversations open faster, and the mouse wheel keeps up with your hand. And a batch of problems is fixed.

New
- The browser: add the BaoCode extension (from the Chrome Web Store, or as a zip loaded unpacked) and agents can open pages, read them, click and type in your own Chrome, Edge, Brave or Arc, signed in as you are. They touch only the tabs you share with them (the BaoCode button in the browser's toolbar shares the tab you're on). The side panel shows the page they're working in as it happens, and you can work in it too. Turn it on or off and install it in Settings → Browser, on macOS and Windows.
- Debugging in the browser: agents read the console and network requests, set breakpoints and step through code, see variables by their source-mapped names, find a page's React and Vue components and event handlers, look into performance, memory and unused CSS, block, mock and rewrite requests, and run a tab as on a phone or a slow network.
- A debugging history of the browser: the pages, requests and console errors and warnings of the tabs you share are kept as they happen, with no recording to start. Say "saving just failed" and the agent looks it up itself. Detailed history keeps request and response bodies too, and your clicks and typing (never passwords). It stays on this computer; Settings shows how much room it takes and clears it, and you're told once it passes 1 GB.
- Show the agent how: an agent can ask you to do something once in the browser, keep each step as a file in the project, and do it again in your browser later.
- Making pictures: agents generate images with your upstreams' image models (the Images API, chat interfaces such as OpenRouter's and Gemini's, Codex's gpt-image-2). Pick the default image model in Settings → Models, or Ask each time to choose in the chat; image models stay out of the chat's model picker.
- Pictures in the chat: what a tool returns as a picture (an image file read, a browser screenshot, an MCP tool's image) and local images in a message show in the conversation. Click one to see it whole, and ← → go through every picture in the chat; right-click to open it in the side panel or the IDE, copy its path or show it in Finder. Image files open in the side panel too.
- The built-in core: BaoCode's own Claude Code core, with CLAUDE.md, skills, subagents, commands, hooks, plugins and MCP servers, on remote hosts too. Switch in Settings → General → Claude Code → Core: the CLI where Claude Code is installed, the built-in core otherwise. The built-in core uses only the upstreams added in Settings → Models; pick the CLI for a Claude subscription.
- Reviewing changes beside the chat: the side panel's editor shows an agent's pending changes in the code, as the IDE does, each part to undo or keep on its own. The bar above goes to the previous and next change and keeps or undoes a file, or everything at once. The side panel's editor finds and replaces too.
- Live usage: while an agent works, the time so far, the writing speed and the tokens roll by under the status line; a finished turn shows its time, speed, cost and tokens, still there when the session is opened again.
- The status line's musings are now mostly about the step just done, its command or file by name.
- Polish in the composer: the button beside the context ring has the model tidy your words, keeping tags, images, code and paths as they are, and it can be undone. Turn it off in Settings → General if you don't need it.
- The side panel can move to the conversation's left: the button in its bar, or Toggle Side Panel Position in the command palette and the View menu.
- Settings → Appearance → As a Reply Comes: Stay at its start stops following once your message reaches the top, so you read the reply from its beginning.
- Settings → General turns off Suggest Next Prompt, saving the extra request each turn; Settings → Appearance hides the times in the sidebar.
- The + on the Stash page starts a new note right there on the right, ready to type in.
- Diagnostics: an event log of windows, views and the theme goes with the diagnostics uploaded from Settings → Updates, to track down windows that stop responding.

Improved
- A long conversation is read from its end, the earlier turns as you scroll to the top: it opens much faster. A very long turn loads a page at a time too.
- The mouse wheel glides, eased and close behind your hand, in the chat, file trees, lists and editors, high refresh rate screens included. Trackpads are as they were.
- Checkpoints keep only the files an agent edited instead of snapshots of the whole project, which could take gigabytes; old checkpoint repositories are deleted, and a session's checkpoints a month unused are tidied away.
- Several thoughts in a row show as one.
- Messages sent while an agent works: queued ones are taken one at a time, and one sent now goes alone.
- Usage statistics: one anonymous ping a day, holding only a random install ID, the version, the operating system and the processor; the Send Usage Data switch is gone from the settings.

Fixed
- Another model or upstream picked while a task runs takes the next message, instead of the one before.
- In a remote project, files from this computer dropped into the composer are copied to the remote host first.
- Networks listed in NO_PROXY (such as Tailscale's 100.64.0.0/10) go around the proxy, and are passed on to Claude Code too.
- The main window opens where it was left, as big, maximized if it was.
- Windows: back in the window after Alt+Tab, the first key types and the window keeps drawing; waking from sleep is no longer taken for a hang.
- macOS: closing a window in full screen no longer leaves a black Space.
- Terminal: functions bash exports (environment modules' module and ml) reach the terminal whole.
- The explorer shows a symbolic link as what it leads to, in remote projects too.
- Stash: a note an agent writes on Windows shows without a restart; the page's filters stay as you last set them; clicking a card's conversation opens the note.
- Sidebar: an agent opened from elsewhere, a new one included, is the one selected; with Stash or Customize shown, the earlier conversation isn't highlighted as well; what has no room gives way instead of being pushed out of its row.
- A subagent continued opens from its row above the composer and goes on in its own card.
- Conversations side by side each have their own side panel bar.
- And smaller fixes: Tab takes the suggestion past an empty IME composition; a table's scrollbar shows again alongside the minimap; inline tags sit centered on their text; a message's editor gets all its room; the Customize details' buttons sit flush right; a link to a heading with a % in it opens.
