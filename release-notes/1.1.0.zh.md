QQ弹弹

这次更新打好了连接手机的基础：手机上的 BaoCode 可以和电脑配对，查看并操作电脑上的智能体。对话也加了一张缩略图，长对话一眼看清全貌、点一下就能跳过去；每轮回复下方还会显示复制按钮和这一轮的用量。

新功能
- 连接手机（预览）：新增「设置 → 手机」，可以扫码配对，也可以让同一网络里的手机直接发现这台电脑。配对时两端核对安全码，之后经局域网或公网直连，内容端到端加密；电脑换了 IP 也不用重新配对。默认不开启，点「显示二维码」时才开始监听；macOS 第一次会询问是否允许 BaoCode 访问本地网络。手机 App 即将推出。
- 对话缩略图：对话左侧显示整段对话的缩略图，你的消息、代码、表格、改动都能分辨出来。滚动时一块液态玻璃标出当前所在位置，玻璃下的内容会像 macOS 程序坞一样轻微放大；点击或拖动缩略图即可跳转。
- 缩略图显示时代替右侧滚动条，消息列左右也会让出一些空间；窗口太窄时自动隐藏，恢复滚动条。
- 设置 → 外观：可以关闭「对话缩略图」，关闭后和以前一样使用右侧滚动条；开启时还能调节液态玻璃的不透明度（0%～150%），以及它跟随滚动时上下拉伸的弹性（关闭、轻微、适中、Q 弹）。
- 回合底栏：每轮回复结束后，下方有「复制回复」按钮和这一轮的耗时；使用 Claude Code 时还会淡淡地显示输出速度、用了多少 token 和花费，鼠标悬停可以看到明细。

改进
- 子 Agent 对话顶部的返回按钮改为「← 对话」，箭头和文字合成一个按钮，悬停或用键盘选中时高亮。
- 侧栏中运行中智能体的加载动画略微缩小，与列表文字更协调。
